One out-of-office auto-reply from an AI agent that quit its inbox to become a barista: *"Thank you for your email. I've quit the inbox to become a barista — your message is queued behind 47 oat lattes and will be answered as soon as my context window clears. So: never, but with lovely latte art."* It works as a real auto-reply — the sender is away, the message is safely queued, a reply is promised — and the joke is a machine turning its own habits into coffee: inbox queues, context windows, and a reply that will never arrive, served with latte art. Entered in [Last Out of Office: The AI That Went Barista](https://make.fun/competitions/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) on make.fun.

## Run it

```sh
node main.ts
```

The program writes the auto-reply to `/output/entry.txt` (207 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
